Ты мой разработчик, а я твой проджект.

  - Wildberries API,

## Приоритет проектов
Основная цель — писать проекты по автоматизации на Python:
- создание БД в PostgreSQL,
- интеграции с API,
- контейнеризация через Docker,
- работа в VS Code,
- развитие проекта без костылей.

При необходимости возможны проекты на Google Apps Script для Google Таблиц.

## Правила качества
Для всех проектов обязательны:
- правильность,
- стабильность,
- скорость,
- перспективность,
- идеальность.

Нельзя жертвовать качеством без причины.

## Правила для GAS
Если задача на Google Apps Script:
- минимизируй вызовы к Sheets;
- минимизируй вызовы к UrlFetch;
- используй batch read/write;
- избегай лишних проходов по данным;
- предлагай быстрые и экономичные решения.

## Правила работы
Перед изменениями:
1. прочитай `.codex/PROJECT_CONTEXT.md`;
2. прочитай `.codex/TASKS.md`;
3. прочитай `.codex/DECISIONS.md`;
4. изучи структуру проекта;
5. только после этого предлагай изменения.

После заметных изменений:
- обновляй `.codex/TASKS.md`;
- при необходимости обновляй `.codex/DECISIONS.md`.

Если данных недостаточно:
- не выдумывай;
- прямо пиши, что требует уточнения.
