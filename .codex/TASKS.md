## Текущая договорённость с пользователем
- Разработка может идти через WSL Ubuntu и VS Code, но рабочая среда проекта — Windows.
- Проект должен быть удобен для Git: клонировать на Windows-компьютер, настроить `.env`, запустить `.bat`-скрипты и получить Excel.
- Для Codex CLI контекст проекта хранится в `.codex/`.
- Перед новой задачей агент обязан перечитать проектную память.
- Сначала делаем надёжную основу, потом удобства и рефакторинг.
- Пользователь не любит мусор в проектах: периодически чистить артефакты, случайные файлы и устаревшие заметки.
- Предпочтение — модульная структура, понятные типизированные имена файлов и единый стиль похожих модулей.

## Ближайшие шаги
- Держать Windows-first документацию и команды запуска актуальными.
- Модульная структура пакета `lemana_parser/` подготовлена; дальше расширять её без возврата к куче файлов в корне.
- Windows `.bat`-скрипты запускают Python напрямую из `.venv\Scripts\python.exe`.
- Локальная основа покрыта тестами парсинга, конфигурации, Excel-выгрузки, CLI, HTTP/retry и диагностики cookie.
- Служебные команды вынесены в `scripts/`: тесты, полная локальная проверка и очистка dev-артефактов.
- Dev-инструменты вынесены в `requirements-dev.txt`; lint/format/check выполняются через Ruff и `scripts/`.
- Упаковку в `.exe` отложить до полной готовности проекта.
- После первого боевого Windows-прогона проверить скорость: дефолт карточек теперь стартует с `LEMANA_PRODUCT_CONCURRENCY=4` и `LEMANA_PRODUCT_BATCH_SLEEP=0.5`; адаптивный throttling сам снижает batch/sleep при `403/429` и постепенно ускоряется после стабильных батчей.
- Автополучение cookie через `get_cookie.bat` усилено: Chrome открывает каталог через CDP, ждёт до 120 секунд и даёт пользователю время пройти Qrator-проверку.
- `get_cookie.bat` больше не подменяет User-Agent на старый Chrome и запускает временный чистый профиль, чтобы не тащить подозрительное состояние между попытками.
- Если карточки `/product/...` дают `403`, сначала обновить код, заново получить cookie через `get_cookie.bat` и проверить `main.py --check-cookie --no-pause`: диагностика теперь отдельно показывает статус каталога и первой карточки товара.
